# My website 🚀

This is my personal website.
I use this webiste to present some information about myself. I also use it as a playground to try out new technologies from time to time.
This iteration of my website was built with Vite + React + TypeScript + CSS Modules.

## Getting Started

Requires Node.js `^20.19.0 || >=22.12.0` and npm 11.13.0.

```bash
npm run dev
```

## Testing

```bash
npm test
```

Runs the Playwright end-to-end suite against a production build.
